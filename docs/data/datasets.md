## 1. 140K Real and Fake Faces (Combined Visual Dataset)

### Dataset Description
Derived from `docs/Deep-Fake-Detection-using-advanced-CNN-architectures-and-its-comparison-main/Dataset/dataset_info` and training notebooks:
- **Origin**: Constructed by merging two publicly available Kaggle repositories:
  1. `xhlulu/140k-real-and-fake-faces`: Contains 70,000 real faces from Nvidia's Flickr-Faces-HQ (FFHQ) dataset, paired with 70,000 synthetic faces generated by StyleGAN (sampled from the 1 Million Fake Faces contribution to the Facebook Deepfake Detection Challenge).
  2. `ciplab/real-and-fake-face-detection`: Supplementary real and manipulated face crops.
- **Total Images**: $142,356$ total images ($71,178$ authentic human faces, $71,178$ synthetic AI-generated faces).
- **Resolution**: Stored at $256 \times 256$ pixels, downsampled during data generation to $224 \times 224$ pixels.

### Verified Splits & Counts from Notebooks
Across the training notebooks in `docs/.../`, data loaders read from standard subfolder structures (`real_vs_fake/real-vs-fake/`):
- **Training Set (`train/`)**: $\sim 100,000$ images (e.g. evaluated at $3125$ steps $\times$ batch size $32 = 100,000$ images).
- **Validation Set (`valid/`)**: $\sim 20,000$ images (used for learning rate reduction and early stopping monitoring).
- **Test Set (`test/`)**:
  - In `custom_cnn`, `densenet`, and `DeepFake-CNN-Custom.ipynb`: Evaluated on a strictly balanced $20,000$-image test set ($10,000$ class 0 [Fake], $10,000$ class 1 [Real]).
  - In `vggface (2).ipynb`: Evaluated on $21,591$ images ($10,735$ class 0, $10,856$ class 1).

### Class Mapping in Loaders
- `0`: **FAKE** (AI-generated / manipulated)
- `1`: **REAL** (Authentic portrait photograph)

### Known Biases & Forensic Limitations
1. **Frontal Pose Dominance**: The FFHQ and StyleGAN distributions predominantly feature aligned, centered facial portraits with direct eye contact.
2. **Generator Homogeneity**: Synthetic faces are primarily derived from early StyleGAN generator checkpoints. While effective for detecting GAN boundary artifacts, modern diffusion models (FLUX, Stable Diffusion 3) produce fundamentally different noise distributions.
3. **Demographic Skew**: Inherits demographic distributions present in Flickr and public social media uploads.

## 2. Deep Voice: DeepFake Voice Recognition

### Dataset Description
Derived from `docs/.../Deepfake Voice Detection/Dataset/dataset_info` and Colab notebook `deep_fake_voice_recognition.py`:
- **Source**: Kaggle repository `birdy654/deep-voice-deepfake-voice-recognition`.
- **Format**: High-quality uncompressed `.wav` audio recordings sampled at $16\text{ kHz}$.
- **Directory Structure**:
  - `/KAGGLE/AUDIO/REAL/`: Original human voice recordings (e.g. `linus-original.wav`).
  - `/KAGGLE/AUDIO/FAKE/`: Synthetic or converted speech samples (e.g. `linus-to-margot.wav` generated via voice conversion).

### Class Balance & Resampling
The raw dataset contains class imbalance (significantly more authentic recordings than manipulated samples). In `deep_fake_voice_recognition.py`, class balance is enforced using **`RandomOverSampler`** from the `imblearn` library:
```python
ros = RandomOverSampler(random_state=42)
X_resampled, y_resampled = ros.fit_resample(X, y)
```
Data is partitioned using an 80/20 train/test split (`train_test_split(..., test_size=0.2, random_state=42)`).
